# Ночная смена — online starter

## Что уже есть
- настоящий WebSocket-сервер;
- создание комнат;
- код комнаты;
- до 6 игроков;
- синхронизация позиций;
- запуск игры после подключения игроков.

## Запуск на компьютере

Нужен Node.js 20+.

```bash
npm install
npm start
```

Открой `http://localhost:3000`.

## Как дать доступ друзьям

Для игры через интернет сервер нужно разместить на хостинге, который поддерживает Node.js и WebSocket. После публикации друзья открывают адрес сайта и вводят код комнаты.
